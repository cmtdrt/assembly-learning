D'abord on build l'image docker
docker build --platform linux/amd64 -t asm-env .

Puis on peut la lancer 
docker run --platform linux/amd64 -it --rm -v $(pwd):/workspace asm-env

Pour vérifier l'architecture de l'environnement
uname -m 
--> ça doit donner x86_64

Prend le ficher .asm et le compile en code machine en produisant un fichier .o
nasm -f elf64 01-hello/main.asm -o hello.o

Linker: transforme le fichier .o en programme exécutable
ld hello.o -o hello

Exécute le progamme
./hello
